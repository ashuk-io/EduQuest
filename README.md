🎮 EduQuest (Gamified Learning Platform)

🚀 Overview EduQuest is a React-based gamified educational platform designed for both students and working professionals. It transforms learning into an engaging experience by combining game mechanics with educational content.

✨ Features

🏆 Leaderboard – Compete with peers and track your progress
🎯 Levels & Stages – Unlock new challenges as you advance
❓ Problems & Questions – Solve quizzes and coding challenges
🎁 Rewards System – Earn points, badges, and achievements
👨‍🎓 For Everyone – Suitable for students and professionals alike
🔧 Under Development – Actively evolving with new features
